GDB x 命令详解 ​

此条由kimi k2.6 根据 gdb 内部输入 help x 的内容翻译整理得到

基本语法 ​

x/FMT ADDRESS

  • ADDRESS：要查看的内存地址表达式

  • FMT：[重复次数][格式字母][大小字母]

格式字母 ​

字母含义
o八进制 (octal)
x十六进制 (hex)
d十进制 (decimal)
u无符号十进制
t二进制
f浮点数
a地址
i指令
c字符
s字符串
z十六进制，左侧补零

大小字母 ​

字母含义字节数
bbyte (字节)1
hhalfword (半字)2
wword (字)4
ggiant (巨字)8

常用示例 ​

bash
# 查看栈顶 4 个 4 字节字（十六进制）
x/4wx $rsp

# 查看接下来 10 条汇编指令
x/10i $pc

# 将 rdi 指向的内容作为字符串显示
x/s $rdi

# 以字节为单位显示 buf 的 20 个字节
x/20bx buf

# 以 8 字节为单位显示数组内容
x/4gx &array

负数：向前（低地址）查看 ​

栈向低地址增长时，用负数往"栈底方向"（高地址）查看：

bash
# 从 $rsp 向低地址方向显示 4 个字
x/-4wx $rsp

默认值继承 ​

GDB 会记住上一次的设置，下次只输入 x 即可：

继承项说明
格式字母上次用的 x/d/s/i...
大小字母上次用的 b/h/w/g...
重复次数上次写的数字，没写就是 1
地址上次 x 或 print 结束的位置

示例：地址自动跟进 ​

bash
# 第一次查看
x/4wx 0x601000
# 0x601000: 0xdeadbeef  0xcafebabe  0x12345678  0x87654321

# 第二次只输入 x，自动从 0x601010 开始
x
# 0x601010: 0x11111111  0x22222222  0x33333333  0x44444444

# 继续
x
# 0x601020: 0x55555555  0x66666666  0x77777777  0x88888888

示例：与 print 共享地址 ​

bash
print &arr[5]
# $1 = (int *) 0x7fffffffe014

# 紧接着用 x，自动使用该地址
x/wx
# 0x7fffffffe014: 0x00000042

完整调试流程 ​

bash
# 查看字符串
x/sb 0x400620
# 0x400620: "Hello World"

# 继续看后面，自动用 sb 格式，地址跟进
x
# 0x40062c: "foo bar"

# 换十六进制查看
x/12xb 0x400620

# 之后只输入 x，默认 /12xb，地址自动跟进
x
